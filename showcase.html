FAQ

Frequently Asked Questions

Do I need to know coding to use this template?

Basic HTML/CSS knowledge is helpful for customization, but not required for setup and deployment. The documentation covers every customization step. The Admin CMS lets you manage all content (packages, blog posts, enquiries) without touching code.

Can I rename the agency and rebrand everything?

Yes, completely. The company name, logo, colors, fonts, phone numbers, leadership team, and all content are easily replaceable. The DOCUMENTATION.md includes a full rebranding checklist.

Does it have a real backend / database?

The current version uses the browser's localStorage for data persistence — perfect for a single-site deployment. The DOCUMENTATION.md includes a full Firebase upgrade guide if you need a real multi-user backend. Firebase free tier is sufficient for most travel agencies.

Will enquiry forms send real emails?

Yes. With the included EmailJS integration (10 minutes to set up), every enquiry triggers an admin notification email and a customer auto-reply. Free plan covers 200 emails/month.

Can I sell the modified template to my clients?

The Single-Use License lets you deploy it for one client. To build websites for multiple clients, you need the Agency License (₹9,999 one-time).

How do I deploy it?

Drag the folder to netlify.com/drop — it's live in 60 seconds. No server, no database, no hosting complexity. The included netlify.toml handles SPA routing and security headers automatically.

What support is included?

30 days of email/WhatsApp support covering: setup, EmailJS configuration, deployment, and basic customization guidance. Advanced custom development is available as a separate paid service.

Is it mobile responsive?

Yes. Every page is fully responsive and tested from 320px (small phones) up to 4K displays. The mobile navigation drawer, touch-friendly modals, and responsive grids are all included.
