# Icons Required for PWA

Place the following icon files in this folder:

| File | Size | Purpose |
|---|---|---|
| `icon-16.png` | 16×16 | Browser favicon |
| `icon-32.png` | 32×32 | Browser favicon (HiDPI) |
| `icon-192.png` | 192×192 | PWA icon (Android) |
| `icon-512.png` | 512×512 | PWA splash screen |

## How to Generate Icons

Option 1 (Recommended): Use https://realfavicongenerator.net
- Upload a 512×512 logo image with the "V" Vayu emblem
- Download the icon pack and place files here

Option 2: Use https://favicon.io/favicon-generator/
- Text: V | Font: Playfair Display | Color: #C5A880 | Background: #090D12

Also place `favicon.ico` in the root `/` directory.
